# BBB-Test-Server-Notify
Get a Discord message whenever your BuiltByBit test server starts.

BBB Test Server Notify is a small plugin that sends a message to your Discord channel through a webhook as soon as a server is starting.

Sends a Discord embed automatically when the server starts
Shows the server name, which can be set in the config or taken from your MOTD
Can show the server address or a public address you set yourself for servers behind a panel
Title, description, color, footer, webhook username and avatar can all be changed
Sends the webhook asynchronously, so it doesn't slow down startup
No commands and no permissions, so players can't trigger or change anything in-game
No dependencies, no license checks, no tracking
